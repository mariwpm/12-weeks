# Бронь без конфликтов

Учебный веб-сервис бронирования компьютерных рабочих мест образовательной организации. Сервис гарантирует, что один ресурс не будет забронирован на пересекающееся время.

## Стек технологий
- **Клиент:** HTML, CSS, JavaScript
- **Сервер:** Node.js 22+, Express 5
- **БД:** PostgreSQL 18.6
- **Безопасность:** JWT (jsonwebtoken) + bcryptjs

## Функционал
- Роли: `user` (просмотр, бронь, отмена своей) и `admin` (управление ресурсами, отмена чужих, аудит).
- Рабочие часы: ежедневно 08:00–22:00 МСК. Шаг 30 минут.
- Защита от пересечений на уровне БД (уникальный индекс слотов).
- Защита от двойных нажатий (Idempotency-Key).

## Запуск проекта локально
1. Убедитесь, что установлен PostgreSQL 18.6 и Node.js 22+.
2. Создайте БД и пользователя в `psql`:
   ```sql
   CREATE USER bbc WITH PASSWORD 'bbc_dev_password';
   CREATE DATABASE bbc OWNER bbc;
3. Скопируйте .env.example в .env и при необходимости поменяйте пароли.
4. Установите зависимости: npm install
5. Примените миграции: npm run migrate
6. Заполните БД тестовыми данными: npm run seed
7. Запустите сервер: npm start
8. Откройте http://localhost:3000
